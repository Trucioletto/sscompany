取り扱うデータと、その理由

このページを送るために、これをホストするサーバーは、必然的に訪問者の IP アドレス、リクエストの日時、要求されたページ、ブラウザのユーザーエージェント文字列を受け取ります。これは選択ではなく、インターネットの技術的な要件です。IP アドレスがなければ、ページを届ける宛先がありません。

これらの記録はホスティング事業者のサーバーログに書き込まれ、本サイトを配信する目的と、サービス妨害攻撃などの不正利用から守る目的にのみ使われます。訪問者のプロファイリングに使うことはなく、ほかのデータと結び付けることもありません。

当社は、カリフォルニア州法にいう意味において、訪問者の個人情報を販売せず、クロスコンテキスト行動広告のために共有することもありません。本サイトには、そのいずれかを行う仕組みがありません。

法的根拠

法的根拠は、本ウェブサイトを運営し安全に保つことについての、GDPR 第6条第1項（f）に基づく管理者の正当な利益です。この取扱いに同意は必要なく、クッキーその他の追跡技術も使用していないため、同意は求めていません。

サイトのホスティング

本サイトは GitHub Pages 上でホストされ、Fastly のコンテンツ配信ネットワークを通じて配信され、Cloudflare を経由してお手元に届きます。Cloudflare は両社の前段にあり、ブラウザからの接続を終端するため、IP アドレスを最初に受け取るのは Cloudflare です。三社はいずれも処理者にあたり、いずれも米国に設立されているため、ページを配信すること自体が、上記の技術データを国境を越えて移転することになります。当該データが、そうした移転を制限する地域（たとえば欧州連合）で生じた場合、その移転は、三社が取得している EU・米国データプライバシーフレームワークの認証と、2023年7月10日の欧州委員会による十分性認定に依拠します。三社によるデータの取扱いを定めた文書は、 GitHub Privacy Statement、 Fastly Privacy Policyおよび Cloudflare Privacy Policy。

訪問者の権利

GDPR 第15条から第22条に基づき、訪問者は管理者に対し、自身の個人データへのアクセス、その訂正、消去、取扱いの制限を求めることができ、正当な利益に基づく取扱いに異議を唱えることができます。ただし、本サイト自体が取り扱っているデータは本人の身元と結び付いていないサーバーログの記録だけであるため、追加の情報がない限り、管理者が該当するデータを見つけられないことが通常です。

データ保護監督機関に苦情を申し立てる権利もあります。管理者はイタリアに設立されているため、所轄の監督機関はイタリアの Garante per la protezione dei dati personali です。欧州経済領域の居住者は、自国の監督機関に連絡することもできます。
